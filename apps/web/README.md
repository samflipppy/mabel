# Mabel office dashboard

The owner does not have to log in. He gets texts. This is for an office manager and the monthly report.

Empty until a shop has leads. No made-up customers.

```bash
npm install
npm run dev
```

Talks to the API at `NEXT_PUBLIC_MABEL_API_URL` (default `http://127.0.0.1:8000`). Name only. The admin token is entered on the Settings and Overnight pages. It is not in this repo.
